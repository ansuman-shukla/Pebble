# Plan: World v1, making the world real

Execution brief for `docs/design/10-world-v1.md` (the bible; read it first). Phase B stays closed until the
**World v1 critic checklist** at the end of this file passes. Decisions D77-D96 are the design; each stream records
its own implementation decisions in its block of 5 (D97 onwards, table below).

## How the work runs

- **Waves.** Wave 1 starts at once and in parallel; each later wave branches from `main` after the previous wave is
  merged. Inside a wave, streams own **disjoint files** (the "Owns" column); anything not listed is read-only for
  that stream.
- **Seams** (append-only, the only files several streams in one wave may touch; the integrator resolves by keeping
  every row): the dispatch tables in `sim/actions.py`, the tick hook list in `sim/simulation.py`, the `WORK_TASKS`
  rows in `sim/doing.py`, the line registry `observability/lines.py`, role routing rows in `brains/profile.py`, the
  check registry `backend/scripts/checks/__init__.py`. Generated files (`frontend/openapi.json`,
  `frontend/src/lib/client/*.gen.ts`) are never hand-merged: rerun `./scripts/pnpm.sh update-openapi`.
- **Contract freeze.** C1 owns `world_api/models.py` and freezes contract v1 in wave 1 (`contract_v1.json`). After
  that, a model change needs a C1 follow-up PR and a decision row; other streams only implement behind the frozen
  models. New actions answer with the existing `not_yet` refusal until their stream lands.
- **Checks.** X0 creates `backend/scripts/world_run.py` with a check registry; every stream adds its headless checks as
  one module `backend/scripts/checks/<stream>.py` (owned by that stream) and runs `python -m scripts.world_run --days N
  --only <stream>`. The critic loop runs them all.
- Worktrees, ports, verify chain, commit/PR rules: `program.md`/`AGENTS.md`. Each stream = one branch
  `ansuman/<type>/<slug>` + one PR (split into stacked PRs if > ~800 changed lines). Snapshot version 3 and world
  generator m4.0 mean fresh runs; nobody migrates old runs.
- **Integration per wave:** an integrator merges the wave's PRs in the listed order once approved, reruns the full
  verify chain and the wave's checks on `main`, and reports breakage back to the owning stream.

## Wave 1: foundations

### X0 · Seams (S, hours; merge first)
- **Scope:** no behaviour change. Split `sim/actions.py` into `actions.py` (dispatch tables start/advance/finish,
  interrupts, `not_yet`), `movement.py` (walk, follow, flee, pace, walk_ahead), `destinations.py` (`_resolve*`,
  beside), `resting.py` (rest, sleep, collapse), `doing.py` (gather, eat, drink, work + `WORK_TASKS`, farm, store),
  `exchange.py` (say, pick_up, drop, give, store_in_reach). Tick hook list in `sim/simulation.py` (per tick, local
  dawn, local midnight). State v3 skeleton in `sim/state.py` + `sim/snapshot.py` with defaults: citizen `group`,
  `titles`, `known_deeds`, `held_by`, `confined_until`, `run_left_s`; animal `phase`, `goal`, `speed_mps`, `gait`,
  `target`, `remains_until`; world `slot_claims`, node arrays (`node_stock`, `node_stage`, `node_regrow_at`),
  `stores` (id → owner, items), `tax_owed`, `deeds`, `standing`, `bonds`, `day_of_week`. Run harness
  `scripts/world_run.py` + `scripts/checks/__init__.py` registry.
- **Owns:** `sim/actions.py` + the five new modules, `sim/simulation.py`, `sim/state.py`, `sim/snapshot.py`,
  `scripts/world_run.py`, `scripts/checks/`, test import updates.
- **Acceptance:** full verify chain; a 10-day `citizens_run` with the same seed gives the identical event-type
  sequence hash before and after the split; snapshot v3 round-trips; old v2 snapshots start a new run (D58).
- **Critic:** none visible (refactor).
